# C Programming Project

## 📌 Overview
This repository contains simple and advanced programs written in **C language**.  
The goal is to practice core concepts like variables, loops, functions, pointers, data structures, and algorithms.

## 🚀 Features
- Beginner-friendly C programs
- Examples of data structures (arrays, linked lists, stacks, queues)
- Algorithm implementations (sorting, searching, recursion)
- Modular and well-commented code

## 🛠️ Requirements
- GCC compiler or any C compiler
- Basic knowledge of C programming
- Git (to clone the repository)
